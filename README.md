# DRI Calculator — Tactical Machine Vision Configurator

A high-fidelity, technical web application for calculating **Detection, Recognition, and Identification (DRI)** ranges based on Johnson's Criteria. Designed with a premium, "authoritative" aesthetic for defense and engineering applications.

## 🎯 Key Features

- **Dual-Camera Comparison**: Side-by-side analysis of RGB and Thermal (LWIR) sensor performance.
- **Dynamic FOV Visualization**: Interactive SVG-based field-of-view visualization with technical grid overlays.
- **Johnson Criteria Engine**: Configurable cycle counts and probability levels (N50, N70, N90).
- **Comprehensive Presets**: Built-in support for industry-standard sensors (Sony, FLIR, Basler).
- **Target Analysis**: Multiple target profiles (Person, Buoy, RIB, USV) with real-world dimensions.
- **Unit Flexibility**: Toggle between Meters, Feet, and Nautical Miles.

## 🛠️ Technology Stack

- **Core**: Vanilla HTML5, CSS3, and modern JavaScript (ES6+).
- **Rendering**: SVG for visualization and Canvas for pixel-on-target previews.
- **Typography**: Inter (UI) and JetBrains Mono (Data).
- **Aesthetics**: Hard-edged, dark-mode technical interface with parchment highlights.
